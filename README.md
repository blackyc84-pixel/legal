# 분쟁 검토

현장(프로젝트)별 법률분쟁을 정리하고, 쟁점 검토와 다음 대응을 한 화면에서 보는 도구입니다.

법률 자문이 아닙니다. 법령 조문은 메모로만 남기고, 최신 법령은 따로 확인합니다. 처음 열리는 사건은 모두 예시이며 실제 사건번호가 아닙니다.

## 실행

```bash
node server.mjs
```

브라우저에서 http://127.0.0.1:3000 을 엽니다. 데이터는 `data/store.json`에 저장됩니다. 파일이 없으면 `data/sample.json`을 복사해 만듭니다.

## 화면

- 오늘 할 일: 가까운 기일, 기한이 있는 대응, 검토 메모가 없는 사건
- 사건: 사실관계, 쟁점, 우리 입장, 상대 입장, 리스크, 검토 결론
- 대응: 준비서면·증거·기일출석 같은 할 일과 상태
- 대응 메모: 위 내용을 한 장으로 복사

## 테스트
